About Voanisa

关于 Voanisa

Voanisa is a local-first music library for macOS. It imports your own audio files into ~/Music/Voanisa, keeps them in a SQLite library with playlists, and plays them without a cloud service or a store account. Probing, tags, cover art, hashing, the library file and decoding all live in a portable Rust core, so the platform layer is only the window and the system integration.

Voanisa 是一个 macOS 本地音乐库。它把你自己的音频文件导入 ~/Music/Voanisa，用 SQLite 管理曲库与歌单，直接播放，不需要云服务，也不经过任何商店账号。文件探测、标签、封面、哈希、曲库文件与解码都放在可移植的 Rust 核心里，Swift 只负责窗口与系统集成。

Why Voanisa?

为什么选择 Voanisa？

  • Your files, your library. Import single files or whole folders; each one is copied into the library, tagged, hashed and deduplicated. Nothing is uploaded and nothing is locked into an account.
  • One decoder for everything. MP3, AAC, ALAC, FLAC, WAV, AIFF, CAF, Ogg Vorbis, Opus, WavPack and Monkey's Audio all decode through the same Rust path, so every format behaves the same.
  • Built to be portable. Probing, tags, cover rendering, the SQLite library and the JSON snapshot are platform-independent Rust with tests, which keeps the macOS layer thin.
  • Covers that keep up. Give a whole import one cover, change a single song's cover from its context menu, or drag an image straight onto the cover box.
  • 文件属于你。可以导入单个文件或整个文件夹；每个文件都会被复制进曲库、读取标签、计算哈希并去重。不上传，也不锁定在任何账号里。
  • 一种解码路径。MP3、AAC、ALAC、FLAC、WAV、AIFF、CAF、Ogg Vorbis、Opus、WavPack 与 Monkey's Audio 都走同一套 Rust 解码，行为一致。
  • 为可移植而写。探测、标签、封面渲染、SQLite 曲库与 JSON 快照都是带测试的跨平台 Rust，macOS 那一层因此很薄。
  • 封面跟得上操作。整批导入可以统一用一张封面，右键即可更换单曲封面，也可以把图片直接拖到封面框上。

Install

安装

  1. Download Voanisa-1.0.1.dmg from the Download Page(Click to open) or the releases page.
  2. Open the DMG and drag Voanisa onto the Applications shortcut.
  3. Launch Voanisa and press Import Audio (⌘O) to add your first files.
  1. 从下载页面（点击跳转）或 Releases 页面下载 Voanisa-1.0.1.dmg。
  2. 打开 DMG，把 Voanisa 拖到 Applications 快捷方式上。
  3. 启动 Voanisa，点「导入音频」（⌘O）添加第一批文件。

The released builds are signed but not notarized, which needs a paid Apple Developer account. If macOS reports an unidentified developer, either right-click Voanisa in Applications and choose Open, or clear the quarantine flag:

发布的版本已签名，但未公证（公证需要付费的 Apple 开发者账号）。如果 macOS 提示「无法验证开发者」，可在「应用程序」中右键 Voanisa 选择打开，或清除下载隔离标记： 

$ xattr -dr com.apple.quarantine /Applications/Voanisa.app

Usage

使用方法

  • Import — press Import Audio, ⌘O, or drop files onto the window. Keep the songs you want with the red dots, then press ⌘Enter.
  • Play / pause — double-click a song or use the play/pause button.
  • Reorder songs — drag a song between the two songs you want it to sit between.
  • Delete a song — select it and press ⌘D or Delete; the file moves to the Trash.
  • Rename a song — right-click it and choose Rename; the new name is written into the file's tags too. Two songs may share a name, so the dialog only warns.
  • Playlists — create one in the sidebar; the sheet searches your library and remembers the order you pick.
  • Repeat mode and language — the playback-mode button at the top, and Settings in the sidebar.
  • One song, many playlists — the Add to Playlist submenu ticks playlists on and off, so one pass covers all of them.
  • Long drags — dragging a song into the top or bottom edge scrolls the list, so a distant drop needs a single gesture.
  • Updates — Settings → Check for Updates asks GitHub for the newest release.
  • 导入 —— 点「导入音频」、按 ⌘O，或把文件拖到窗口上；用红点决定哪些要导入，然后按 ⌘Enter。
  • 播放 / 暂停 —— 双击歌曲，或点击播放/暂停按钮。
  • 调整歌曲顺序 —— 拖动歌曲到你想插入的两首歌之间。
  • 删除歌曲 —— 选中后按 ⌘D 或 Delete，文件会被移到废纸篓。
  • 重命名歌曲 —— 右键选重命名，新名字也会写进文件标签；允许同名歌曲，弹窗只会提示。
  • 歌单 —— 在侧栏新建；选择器可以搜索曲库，并按你选中的顺序保存。
  • 循环模式与语言 —— 顶部的播放模式按钮，以及侧栏的设置。
  • 一首歌加入多个歌单 —— 「加入歌单」子菜单是勾选式的，一次可以勾上多个。
  • 远距离拖动 —— 把歌曲拖到列表上下边缘会自动滚动，一次就能拖到位置。
  • 更新 —— 在设置 → 查询最新版本里向 GitHub 查询最新版本。

Requirements

系统要求

macOS Sequoia (15) and above

macOS Sequoia (15) 或更高版本

Audio files on disk. Voanisa keeps its library in ~/Music/Voanisa and needs no Apple Music library.

本地磁盘上的音频文件。Voanisa 把曲库放在 ~/Music/Voanisa，不需要 Apple Music 资料库。

WMA is not supported: macOS cannot decode it and the portable core has no ASF demuxer, so those files are marked unsupported when importing. Convert them to FLAC or MP3 first; Scripts/convert-wma.sh converts a whole folder in one go.

WMA 暂不支持：macOS 无法解码，核心也没有 ASF 解析器，导入时会被标为不受支持。请先转成 FLAC 或 MP3——仓库里的 Scripts/convert-wma.sh 可以一次转完整个文件夹。

Build From Source

从源码构建

Building needs Xcode 16, XcodeGen and a Rust toolchain; Scripts/build-rust.sh compiles the core before every build. The Xcode project is generated from project.yml with XcodeGen, so it is disposable:

构建需要 Xcode 16、XcodeGen 与 Rust 工具链；每次构建前 Scripts/build-rust.sh 会先编译核心。Xcode 工程由 XcodeGen 依据 project.yml 生成，因此是可以随时丢弃的产物： 

$ xcodegen generate
$ open Voanisa.xcodeproj

To build a signed, universal (arm64 + x86_64) DMG into dmg/:

要在 dmg/ 下生成已签名、兼容 Intel 的通用版 DMG： 

$ Scripts/package-dmg.sh

Looking at a packaged image

Scripts/voanisadmgrun mounts a packaged image and opens it in Finder, which is the quickest way to check the install experience: 

$ Scripts/voanisadmgrun              # newest image in dmg/
$ Scripts/voanisadmgrun path.dmg     # a specific image
$ Scripts/voanisadmgrun --eject      # eject it again

To have it as a command, link it somewhere on your PATH: 

$ ln -s "$PWD/Scripts/voanisadmgrun" ~/.local/bin/voanisadmgrun

查看打包好的镜像

Scripts/voanisadmgrun 会挂载镜像并在 Finder 中打开，是检查安装体验最快的方式： 

$ Scripts/voanisadmgrun              # dmg/ 下最新的镜像
$ Scripts/voanisadmgrun path.dmg     # 指定镜像
$ Scripts/voanisadmgrun --eject      # 卸载

想把它变成一条命令，做个软链放到 PATH 里即可： 

$ ln -s "$PWD/Scripts/voanisadmgrun" ~/.local/bin/voanisadmgrun
